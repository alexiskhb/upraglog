What Upraglog Does

Upraglog is a local-first gym workout log. Users can record exercises, workouts, sets, notes, profiles, and app settings in their browser. The app works offline and stores workout data locally unless the user chooses to export, import, back up, or restore data.

Google Drive Access

Google Drive backup is optional and starts only when a user chooses "Backup to Drive" or "Restore From Drive" in the app settings. Upraglog requests this OAuth scope:

https://www.googleapis.com/auth/drive.appdata

The scope is used only to create, find, read, and update the app-owned backup file upraglog-backup.json in Google Drive's hidden app data folder. Upraglog does not request broad access to the user's Google Drive files.

Google User Data Use

  • Accessed data A user-created Upraglog backup JSON file in the Drive app data folder.
  • Purpose User-initiated backup and restore of the workout log.
  • Storage Workout data is local by default. Drive backup data is stored in the user's Google Drive app data folder.
  • Sharing Upraglog does not sell Google user data or share it with advertising platforms, analytics providers, or data brokers.

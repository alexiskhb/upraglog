Overview

Upraglog is a local-first gym workout log. The app is designed to keep workout data in the user's browser by default. Google Drive backup is optional and is used only when the user starts a backup or restore action.

Last updated: 2026-06-17

Information You Enter

Upraglog can store exercises, workout plans, workout logs, sets, notes, profile names, preferences, and imported backup data. This information is stored locally in the browser's IndexedDB database unless the user chooses to export, share, back up, or restore it.

Google Drive Data

If a user chooses Google Drive backup or restore, Upraglog asks the user to authorize this Google OAuth scope:

https://www.googleapis.com/auth/drive.appdata

Upraglog uses this scope only to create, find, read, and update an app-owned backup file in the hidden Google Drive app data folder. The default backup file name is upraglog-backup.json. The app does not list, read, change, or delete the user's normal Google Drive files.

How Information Is Used

  • To display and manage the user's workout log in the app.
  • To export or import backups requested by the user.
  • To save or restore a user-initiated backup in Google Drive's app data folder.

Upraglog does not use Google user data for advertising, profiling, or cross-context tracking.

Sharing And Transfer

Upraglog does not sell Google user data. The app does not transfer Google user data to advertising platforms, analytics providers, or data brokers. The app may export or share files only when the user intentionally uses an export or share action provided by the browser or operating system.

Upraglog's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy , including the Limited Use requirements.

Storage And Security

Local workout data is stored in the user's browser. Google Drive backup data is stored in the user's Google Drive app data folder and is protected by the user's Google account controls. OAuth access tokens are used in the browser to complete the requested Drive action and are not stored by Upraglog.

User Choices

  • Users can use Upraglog without Google Drive backup.
  • Users can export local backup files from the app settings.
  • Users can revoke Upraglog's Google access from their Google Account permissions.
  • Users can clear local app data through their browser storage controls.

Contact

For privacy questions, use the user support email shown for Upraglog on the Google OAuth consent screen.
